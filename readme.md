# Easy Schedule Planner

This is a web-based application that will allow the user to create unique individual schedules for each day of the week and then have those schedules and timeframes color coded to a analog clock. 

## Instructions for Build and Use

Steps to build and/or run the software:

1. Obtain the web address for the website.

2. Navigate the website from the address.

Instructions for using the software:

1. The user will start on the index page, which will simply show a clock, the current date, and a link to a following page.
2. Click on the link called "Go to schedule."
3. The user will be redirected to the schedules page. From here, the user can navigate the page and find another clock along with 7 schedule planners; one for each day of the week.
4. The user can add times, remove times, and fully reset their schedules once they interact with the displayed data tables.
